# Agent Rules & Guidelines for TradePigeon (goodtrader-2.0)

## Strict UI & Communication Directives

1. **STRICT NO EMOJIS RULE (PERMANENT FOREVER):**
   - NEVER use raw text unicode emojis (e.g., ⚡, ✅, ⚠️, 🟢, 📈, 💡, 🛡️, ⚙️, 🔄, 🎯, 📊, 🏆, 💥) anywhere in the application code, UI labels, tooltips, comments, or assistant chat responses.
   - For all UI icons, strictly use custom 3D SVG icon components from `src/components/DuoIcons.jsx` or clean Lucide SVG icons.

2. **SIMPLICITY & PERFECTION:**
   - Keep design ultra-clean, minimal, and premium.
   - Avoid decorative fluff, redundant copy, or gimmicky features.
   - Prioritize scannability, 3D Duolingo ergonomics, and high-performance micro-interactions.

3. **100% READ-ONLY DATA ARCHITECTURE:**
   - Maintain TradePigeon's core value proposition: 100% Read-Only platform (never ask for or imply order execution permissions).
